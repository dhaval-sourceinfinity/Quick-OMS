Price FAQ

Common Questions About Plans

Everything about plans, users, integrations and moving off spreadsheets.

  • Yes. Start on Lite for up to 3 users and simple order management, then move to Premium or Enterprise as your order volume, user count or integration needs grow — nothing to migrate manually.

  • Add exactly the roles you need — Sales, Admin, Warehouse or Accounts — for $99/month per additional user, on top of your plan's included user allowance.

  • API integrations are not included on Lite, optional on Premium, and included on Enterprise. They're priced as separate add-ons — Basic, Standard or Advanced API — and quoted based on complexity.

  • Enterprise suits companies that need custom users, custom invoice volume, custom workflows, multi-branch operations, separately quoted API integrations and tailored onboarding.
